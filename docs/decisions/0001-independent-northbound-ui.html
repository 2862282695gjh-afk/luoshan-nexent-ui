ADR 0001 · Status: Accepted · Date: 2026-09-08

独立 Vue 前端与同源北向代理

Context

用户提供 UI 图片和接口文档，需要可调用北向接口的页面，尚未指定集成仓库。原 Nexent 工作区有未提交的其他改动。

Decision

在独立目录创建 Vue 3 + TypeScript 页面，使用共享 Node HTTP 代理连接北向服务。API Key 只从服务端环境读取。演示与真实模式分离并标识。

考虑过的选项与取舍

直接在 Nexent 前端集成可复用现有组件，但耦合原项目发布和构建，也无法确定用户要求的集成位置。浏览器直接调用配置更少，但暴露租户 API Key 且依赖 CORS。独立工程便于本地查看和单独部署，同源代理增加小型运行进程，但解决凭据分发与 SSE 代理问题。

Consequences

页面不修改原 Nexent 服务。静态资源必须与代理一起运行。当前每个应用实例对应一个 API 用户；接入多用户门户需要复用门户认证和用户凭据映射。页面不添加文档没有的删除接口。没有可联调服务前，仅能完成模拟契约与本地代理验证。
