## 依赖维护记录

本次在原版本范围内更新锁文件中的 DOMPurify `3.4.15 → 3.4.18`、Vite `7.3.6 → 7.3.8` 和 source-map-js `1.2.1 → 1.2.2`，更新后重新通过上述构建与测试。

完整 `npm audit` 仍报告 3 项仅测试依赖告警：`@vitest/mocker` 为 moderate，`tinypool` 和受其影响的 `vitest` 为 critical。npm 提供的自动修复需要将 Vitest 从 3 升级到 5，属于跨大版本迁移，未在本次仓库整理中执行 `npm audit fix --force`。这些依赖不进入生产 `dist`，生产 `server/` 仅使用 Node 内置模块；开发和测试服务仍应仅在受控环境运行。后续升级测试工具后应重新运行单元测试并复查完整审计。
