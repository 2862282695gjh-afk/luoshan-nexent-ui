# 移动端 AI 助手

2026-09-10。参考用户提供的《ai运维助手移动端ui规范》8 张图片，在现有前端内实现响应式移动端。

## 使用与范围

使用相同页面地址，屏幕宽度不超过 767px 时自动切换手机布局，PC 保留原有导航及侧栏。手机首次进入欢迎页，通过左上角菜单打开历史；房屋按钮返回新的空白对话。手机与 PC 共用北向 API、会话状态、错误解析和流式处理。演示模式仍明确标识，真实服务连接失败不会自动切换演示。

- 图 2：浅蓝渐变欢迎页、SVG 助手标识、顶部历史/首页/连接设置入口。
- 图 5、6：文本框自动增高、展开编辑、清空、收起保留草稿和发送。使用设备真实键盘，不绘制模拟键盘。
- 图 7：蓝色用户气泡、白色 Markdown 回答区、复制、定位最新和停止生成。
- 图 8：模态历史抽屉、搜索、时间筛选、新建、会话切换和重命名；支持遮罩关闭和 Escape，焦点由原生 dialog 管理。

沿用用户此前确认的纯文本 Agent 范围，不增加语音录制、拍照、相册或文件上传。图 1 的园区门户和入口浮层属于外部宿主页面，当前交付直接打开助手页面；不模拟门户用户、通知和统计数据。

## 实现

- `src/App.vue`：复用既有会话及 SSE 状态，增加手机导航、历史抽屉与展开输入；桌面/手机尺寸切换保留消息和草稿。
- `src/mobile.css`：独立手机样式、触控尺寸、底部安全区、对话滚动区域。
- `src/components/AssistantEmblem.vue`：参考规范重新绘制的 SVG 助手标识，不依赖外部图片服务。
- 监听 visualViewport 高度调整页面及展开编辑区域；viewport-fit=cover 和 safe-area-inset 预留安全区。

## 验证与边界

生产构建、TypeScript 校验、25 项单元测试、11 项 Chromium 浏览器回归通过。回归覆盖 320/390/430px 手机宽度、400px 短视口、桌面恢复、历史搜索和重命名、抽屉关闭、展开编辑与草稿保留、手机发送/续聊/停止、final_answer 后直接 EOF、错误原因和原有 PC 行为。接口回归采用模拟真实协议，不会创建真实计费对话。

已逐张核对欢迎、历史、对话和展开编辑截图。尚未在 iOS Safari、Android 真机及真实软键盘环境验证；浏览器视口模拟不能替代这部分验证。原后端服务和用户 .env 不作修改。

## 手机访问部署

手机上的 127.0.0.1 指手机自身，不能访问电脑服务。通过已配置访问控制的园区域名进入，或在允许的局域网测试环境将生产服务 HOST 设为 0.0.0.0，手机与服务器保持网络互通后访问 http://服务器局域网IP:5180/。后端地址仍配置在服务端 NEXENT_BASE_URL，不在手机浏览器内设置。网页复制功能依赖浏览器安全上下文，生产使用 HTTPS；HTTP 环境复制失败时页面会提示手动选择文本。
