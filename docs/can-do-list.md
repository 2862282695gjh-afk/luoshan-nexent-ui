# Can Do 能力清单

对话输入框上方的 Can Do List 取代了原先的园区补贴、会议室预约和物业报修等泛问题。能力和示例问题参考《测试用例-罗山AI运维助手》中的“用户话术”，其中“知识问答”按用户确认的知识检索问题更新；完整对话页面和悬浮小窗共用同一份清单：

| 能力     | 示例用例                                                    |
| -------- | ----------------------------------------------------------- |
| 知识问答 | 地下室防火应满足什么条件；电梯检测的时候噪声测试怎么执行    |
| 数据分析 | 实时能耗、历史用能、环境趋势（TC-A01、TC-A02、TC-A13）      |
| 预测预警 | 范围体检、单设备告警、预测性检查（TC-B01、TC-B01b、TC-B03） |
| 巡检上报 | 巡检结果上报、异常处理建议（TC-C01、TC-C02）                |
| 运维报告 | 日报、周报（TC-D01、TC-D02）                                |

桌面端鼠标悬停或键盘聚焦某个能力项时，示例面板会在对应能力项上方展开，示例按纵向单列排列；手机端点击能力项也可展开。点击示例只会把问题填入输入框，用户仍可编辑后再发送，不会自动提交对话、创建工单或写入巡检记录。

当前仍由连接设置中选定的已发布智能体处理问题。实际部署应选择具有相应路由能力的园区主智能体，或在发送前切换到对应的已发布智能体。

测试用例明确限制的内容没有放入清单：厂家联系电话不能编造；“确认”只是上下文续接；建单、告警推送、报告推送和定时自动推送均需后端确认流程或真实环境 MCP。
